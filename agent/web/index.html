2. Installation & Windows SmartScreen Trust

Signed by Fedmitigate LLC (Azure Trusted Signing). If SmartScreen displays "Windows protected your PC", click "More info" and then "Run anyway", or run Unblock-File -Path .\pqc-scanner.exe in PowerShell.

3. What All You Can Scan

  • Windows Certificate Stores: Cert:\CurrentUser\My, LocalMachine\Root, LocalMachine\CA.
  • SSH & GPG Keys: User keys in %USERPROFILE%\.ssh (id_rsa, id_ecdsa, id_ed25519).
  • Java Keystores: cacerts, .jks files, and enterprise PKCS#12 bundles.
  • Authenticode Signatures: Embedded digital signatures in DLLs, EXEs, and system drivers.

4. Scan Modes: Quick Scan vs. Custom Path vs. Probe TLS

  • ⚡ Quick Scan Workstation: Audits standard Windows cert stores and user SSH keys in 5-15 seconds.
  • 📁 Custom Path Scan: Recursively audits any folder, UNC network share, or external drive.
  • 🌐 Probe TLS / Endpoint: Probes remote endpoints (e.g. api.company.com:443) for TLSv1.3 and hybrid X25519MLKEM768 key exchange without an agent.

5. How to Read Results

  • Shor's Risk: Classical RSA and ECC asymmetric keys vulnerable to quantum factorization.
  • Grover's Risk: Symmetric keys/hashes requiring upgrade to AES-256 / SHA-384+.
  • HNDL Threat: Key exchanges at risk of "Harvest Now, Decrypt Later".
  • Quantum Resilient: Fully compliant with NIST FIPS 203/204/205.
